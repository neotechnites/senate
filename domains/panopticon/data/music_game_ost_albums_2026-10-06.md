# Game-OST-style DnB / jungle albums: backup artists to Mejer
Date: 2026-10-06

Every link below was checked: SoundCloud links through oEmbed (author and title match), Bandcamp links by fetching the page (HTTP 200, artist and album title match). Follower counts are SoundCloud followers from api-v2 on 2026-10-06. "SC n/a" means I found no SoundCloud account, so there's no follower count.

## Reference set (context)
- **Mejer**: Pineberry Rush https://soundcloud.com/mejermusic/sets/pineberry-rush, Pineberry Hex https://soundcloud.com/mejermusic/sets/pineberry-hex. 67 followers. Contact: mejer.bandcamp.com, YouTube, Spotify.
- **Air Runner(s)**: the album is **"Air Runners OST" by System ST91** (Prague). It's a one-hour soundtrack for a fictional game, made for itch.io's "OST Composing Jam: Overtime" (May 2026). Genre tag "Y2K VGM". Tracks are titled like game screens: Main theme, Character select, Story mode events. https://soundcloud.com/systemst91/sets/air-runners-ost. Free download, with the fictional game's write-up: https://system-st91.itch.io/air-runners-ost. 2,146 followers.
- **YET soundsystem**: 8MB https://yetsoundsystem.bandcamp.com/album/8mb (21 tracks, PS1/PS2 jungle). 277 followers. Germany.
- **Pizza Hotline**: Level Select https://pizzahotline.bandcamp.com/album/level-select. Big (Motorslice OST, vinyl, DJ Mag). Probably too expensive.

## Method
I used SoundCloud api-v2 to map who Mejer and YET follow, what they like and repost, and related tracks (two hops: about 1,000 accounts, with every playlist scanned for OST/PS1 keywords). I also used the Bandcamp discover API on the tags ps1-jungle, playstation-jungle, ps2-jungle, psx-jungle and y2k-vgm, plus web search.
